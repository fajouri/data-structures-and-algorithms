# S05 — Google Colab Studio

Open **`S05_Symbol_Table_Studio.ipynb`** in Google Colab (File → Upload notebook, or use the GitHub tab once published). Use a standard Python runtime. All runnable baseline cells use only the Python standard library.

**Student workflow:** For each section: **Predict → Run → Modify → Explain**. The notebook covers comparable ADT contracts, three storage diagrams, public tests, BST shape experiments, fair benchmarks, interpretation and self-reflection. Student implementation cells contain `TODO` and are not executed automatically until complete; **Runtime → Run all** still succeeds in the starter state. The project also has `starter.py` for longer implementation exercises and `tests/test_contract.py` for repeatable checks.

**Lecturer setup:** Run the notebook once in advance; invite students to explain *why* the update and missing-key rules matter before revealing output. Benchmark timings differ by device and session. Do **not** treat printed example measurements as official assessment scores or general performance results. When working offline, use the reproducible input lists and comparison-count worksheet in `exercises.md`.
