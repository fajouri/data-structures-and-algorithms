# Teaching sessions

The official descriptor specifies **20 sessions of 3 hours**, numbered `S01` through `S20`.

Create each `sessions/SXX/` directory **only when its session is approved for drafting**. This avoids empty folders and filler files before the lecturer approves `course-plan.md`.

A complete session normally contains:

- `README.md` — overview, prerequisites and timed agenda
- `lecture.md` — full academic explanations and worked examples
- `exercises.md` — student-facing tasks without solutions
- `slides.md` — slide content and detailed speaker notes
- `slides.pptx` — editable PowerPoint when supported
- Appropriate runnable Python/C++ examples, tests or notebooks, only when useful

Keep instructor solutions out of the public repository. See [Codex skill](../.agents/skills/dsa-course-builder/SKILL.md).
