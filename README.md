# Data Structures and Algorithms (M12)

Course repository for **Ascencia Malta — MSc in Computer Science (MQF/EQF Level 7)**.

## Course at a glance

- 20 face-to-face sessions, 3 contact hours per session (60 hours)
- 12 ECTS
- Python and C++ practical work
- Official assessment: closed-book written examination (60%) and four programming assignments (40%)

The **official Module Descriptor** takes precedence over the course plan and session materials. The [course plan](course-plan.md) and [course tracker](COURSE_STATUS.md) are published as **DRAFTS for lecturer review**. Their presence in GitHub does not constitute academic approval.

## Where to find things

- [Module descriptor](module-descriptor/): official requirements (PDF to be added).
- [Sessions](sessions/): teaching packages created one at a time after course-plan approval.
- [References](resources/references.md): bibliography from the descriptor.
- [Course builder skill](.agents/skills/dsa-course-builder/SKILL.md): how to generate and validate sessions with Codex.

## Minimal workflow

1. Review the official descriptor and obtain lecturer approval of `course-plan.md`.
2. Ask Codex to use `dsa-course-builder` for a specified session (`S01`–`S20`).
3. Review the produced materials and run the validator.
4. Update the single `COURSE_STATUS.md` tracker.
5. Commit to the existing default branch **only when explicitly authorised**.

No feature branches, PRs, Issues, Kanban, or extra academic governance documents.

> The repository is public. Keep answer keys, instructor solutions, personal information and any restricted learning resources outside it.
